# Внески до відкритого проєкту

Надсилаючи внесок, ви повинні мати право на його поширення. Якщо інше явно не погоджено до прийняття внеску, новий авторський код надається за AGPL-3.0-or-later, а документація й охоронювані матеріали даних — за CC-BY-SA-4.0. Внески до окремих MIT-демонстрацій зберігають їхні MIT-умови. Передання виключних прав автору проєкту не вимагається.

Зберігайте авторство, позначайте суттєві зміни та документуйте походження нових залежностей. Не видаляйте MIT-повідомлення вихідної моделі або Three.js. Не додавайте закритих компонентів, несумісних із відповідною ліцензією.

Не публікуйте облікові дані, приватні виробничі журнали, підписи або персональні відомості. Для зміни даних потрібні опис джерела, версія й контрольні суми. Не видавайте синтетичні дані за виробничі спостереження.
