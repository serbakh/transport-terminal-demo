# Термінал: демонстрація ресурсного та економічного вибору

Сайт: https://serbakh.github.io/transport-terminal-demo/

**[Граф симуляції погрузки: автомобілі, операції та черги](https://serbakh.github.io/transport-terminal-demo/simulation-graph.html)** · [3D-сцена](https://serbakh.github.io/transport-terminal-demo/baseline-3d.html)

Граф відтворює збережену добу для 4/2/2, 9/2/2 і 14/2/2; це вихідний етап, а не анімація нового повного циклу.

Два джерела: вихідна добова модель статті та новий експеримент повного циклу партії 10 000 т. Дані синтетичні; ціни сценарні. Вихідні версії та SHA-256 — у `provenance.json`.

Головна сторінка переглядає збережені прогнози 1836 сценаріїв, перераховує витрати за зміненими ставками та зіставляє вибір із контрольними серіями. Окремі добові журнали й тривимірна сцена збережені як попередня демонстрація. Їхні економічні показники не підміняють нову калькуляцію.

Браузер не запускає Python/SimPy і не виконує новий ML-прогноз. Значення середніх контрольних серій відокремлені від записаних реалізацій seed 10000. Виконання норми в 5/5 повторах не є гарантією.

Для локального перегляду: `python -m http.server 8765`; відкрити http://localhost:8765. Також підтримується пряме відкриття index.html.

Оновлення: у дослідницькому проєкті виконати `python tools/build_demo.py`, перевірити сайт і експортувати файли каталогу demo сюди. Не переносити облікові дані, приватні первинні документи, моделі або повні виробничі журнали. Поточний набір містить тільки підготовлені синтетичні демонстраційні дані. Доступ до закритого репозиторію відвідувачу не потрібний.
