# Термінал: ресурси та прогнози

https://serbakh.github.io/transport-terminal-demo/

За основу взято останню сторінку «Термінал — ресурси та прогнози», збережену в source/terminal-resources-v3.html. Два режими в одному інтерфейсі: вихідний добовий експеримент і новий повний цикл партії 10 000 т. Вкладки: відтворення, прогноз і підбір, тоннаж, економіка.

Прогнози для 1836 сценаріїв та контрольні середні взято зі збереженого дослідження. Вісім повних журналів із seed 10000 повторно відтворено тим самим кодом і звірено зі збереженими тривалістю та витратами. Ціни можна змінювати; години завершення ресурсів індивідуальні. Браузер не навчає ML та не запускає нову симуляцію.
